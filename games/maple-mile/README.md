# Maple Mile

A Canadian commercial real estate arcade game.

Open index.html in a browser, or serve this folder with any static host. No build step or backend required. For GitHub Pages, place these files in the publishing folder.

Steer with arrow keys, WASD, swipes, or the mobile direction pad. Space pauses. Collect orange properties to buy them; green cash pickups add $75k; repairs cost $60k. Rent arrives every 28 moves. Survive 90 seconds with the highest net worth. Edges wrap; your own trail ends the run.

All property names and economics are fictional. Personal best stays in browser storage. Sound is optional. Fonts load from Google Fonts, with local fallback fonts.
